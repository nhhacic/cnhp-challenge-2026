Cài Đặt Bộ Công Cụ Nền Tảng: Git & Node.js

Đây là 2 phần mềm nền tảng cơ bản nhất bắt buộc phải có trên máy tính để máy tính có thể kéo code về và chạy thử trang web. Bạn chỉ cần cài đặt 1 lần duy nhất!

📦

1. Cài Git for Windows

Giúp máy tính hiểu được các thao tác đồng bộ với GitHub để lấy mã nguồn dự án.

  1. Truy cập: git-scm.com/download/win
  2. Chọn "Click here to download" (bản 64-bit cho Windows).
  3. Mở file tải về lên, bấm Next liên tục (giữ nguyên mặc định) cho đến khi bấm Install -> Finish.
⚡

2. Cài Node.js (Bản LTS)

Môi trường chạy web Next.js trên máy của bạn.

  1. Truy cập: nodejs.org
  2. Bấm vào nút màu xanh to có chữ LTS (Recommended for Most Users).
  3. Mở file vừa tải về, bấm Next -> tích đồng ý điều khoản -> Next liên tục -> Finish.
Kiểm tra cài thành công: Mở PowerShell và gõ lệnh sau:
node -v; git --version
02

Cài Đặt Google Antigravity & Kích Hoạt Gói Ultra

Google Antigravity là phần mềm lập trình AI thế hệ mới (Pair Programmer) do Google phát triển. Nó thông minh hơn ChatGPT hay Copilot thông thường vì có thể tự đọc toàn bộ dự án, tự gõ lệnh, tự sửa file và tự kiểm thử!

1️⃣

Tải và cài đặt Antigravity

Tải bản cài đặt chính thức dành cho Windows từ trang chủ antigravity.google.

Sau khi cài xong, mở ứng dụng lên và tiến hành đăng nhập bằng tài khoản Google (Gmail) của Tùng.

2️⃣

Đăng ký & Nâng cấp Gói Ultra (Google One AI Premium)

Gói Ultra cho phép sử dụng mô hình trí tuệ nhân tạo mạnh nhất (Gemini Pro / Flash High Reasoning), cửa sổ ngữ cảnh khổng lồ (2 triệu token) để AI "nhìn thấu" toàn bộ mã nguồn của dự án mà không bị quên hoặc nhầm lẫn.

  • Truy cập Google One AI Premium để kích hoạt gói cước.
  • Nếu tài khoản của Tùng đã có Gemini Advanced / Google AI Pro thì đã có sẵn quyền Ultra.
3️⃣

Chọn Mô Hình AI Đỉnh Nhất Trong Antigravity

Trong Antigravity, nhìn xuống góc dưới cùng bên phải của ô chat (hoặc vào biểu tượng bánh răng Settings ➔ Model Selection) ➔ Chọn Gemini 3.8 Flash (High) hoặc Gemini Pro để có khả năng tư duy và lập trình cao nhất.

Đăng Ký & Thiết Lập Strava API (Đồng Bộ Chạy Bộ)

Để webapp có thể tự động lấy bài chạy bộ từ ứng dụng Strava của các vận động viên, chúng ta cần một chiếc "chìa khóa kết nối" (Strava API). Việc đăng ký này hoàn toàn miễn phí 100%.

1. Đăng nhập và tạo ứng dụng API Strava:

Truy cập đường dẫn: https://www.strava.com/settings/api (đăng nhập tài khoản Strava nếu chưa đăng nhập).

2. Điền mẫu đăng ký theo thông số chuẩn sau:
Application Name: CNHP Challenge 2026
Category: Sports Event hoặc Health/Fitness
Club: Để trống
Website: http://localhost:3026
⚠️ Authorization Callback Domain (Cực kỳ quan trọng):
localhost (Chỉ gõ chữ "localhost", KHÔNG có http:// hay số cổng :3026)
3. Lấy mã số và điền vào dự án:

Sau khi bấm Create, Strava sẽ cung cấp cho bạn Client ID (dãy số) và Client Secret (bấm nút "Show" để xem dãy ký tự bí mật).

// Tạo 1 file tên là .env.local ở thư mục gốc dự án và dán nội dung sau vào:
NEXT_PUBLIC_STRAVA_CLIENT_ID=Dãy_Số_Client_ID
STRAVA_CLIENT_ID=Dãy_Số_Client_ID
STRAVA_CLIENT_SECRET=Dãy_Ký_Tự_Client_Secret
05

Khởi Chạy Ứng Dụng Web Lần Đầu Tiên

Bây giờ là khoảnh khắc kỳ diệu nhất: cài các linh kiện cần thiết và khởi động webapp chạy trên chính chiếc máy tính của bạn!

1. Tải các gói thư viện (Chỉ cần chạy 1 lần):
npm install

Mất khoảng 30s - 1 phút để tải về.

2. Chạy thử 26 ca kiểm tra thể lệ tự động (Automated Tests):
npm run test:rules

Sẽ xuất hiện 26 dòng ✅ [PASS] chứng minh tất cả các điều luật giải chạy Thu Đông đã được lập trình chính xác 100%.

3. Bật máy chủ phát triển (Dev Server):
npm run dev

Mở trình duyệt (Chrome, Edge) và gõ địa chỉ:
👉 http://localhost:3026

06

Cách Làm Việc & "Giao Việc" Cho AI Antigravity

Tùng không cần phải nhớ code hay cấu trúc file phức tạp. Hãy coi Antigravity như một lập trình viên cao cấp ngồi ngay bên cạnh bạn. Bạn chỉ cần giao việc rõ ràng bằng tiếng Việt!

🎯

1. Nói rõ mục tiêu

Nói rõ bạn muốn thêm nút gì, đổi màu gì, sửa quy tắc tính tiền như thế nào. Ví dụ: "Đổi màu thanh menu sang màu cam mùa thu".

📎

2. Dùng phím @ để trỏ file

Khi gõ trong ô chat, bấm phím @ sẽ hiện danh sách file. Ví dụ chọn @challenge_data.json để bảo AI thêm thành viên mới.

✅

3. Bấm Proceed / Chấp nhận

Antigravity sẽ đưa ra kế hoạch và xin phép chạy lệnh hoặc chỉnh file. Tùng chỉ việc đọc và bấm Proceed hoặc Chấp thuận!

Kho Câu Lệnh (Prompt) Mẫu Để Tùng Nâng Cấp App Ngay

Chỉ cần bấm "Copy Prompt" và dán vào khung chat của Antigravity!

👥 Thêm thành viên mới hoặc điều chỉnh danh sách đội
Hãy kiểm tra file data/challenge_data.json và giúp tôi thêm 1 thành viên mới tên là "Nguyễn Văn An" vào đội "Chiến Binh CNHP", giới tính Nam, mục tiêu cá nhân là 20km/tuần. Sau khi thêm, hãy cập nhật lại dữ liệu hiển thị trên bảng xếp hạng.
💰 Điều chỉnh mức tiền thưởng / phạt theo thể lệ mới
Ban tổ chức vừa thông báo cập nhật thể lệ: mức phạt thiếu buổi chạy đổi từ 20.000đ lên 30.000đ/buổi, và thưởng cho đội Nhất tuần tăng lên 200.000đ. Hãy tìm các vị trí tính toán trong src/lib/rules-engine.ts và giao diện để cập nhật lại đúng theo số tiền mới này, đồng thời chạy lại npm run test:rules để đảm bảo không bị lỗi logic.
📊 Thêm nút xuất file Excel / CSV báo cáo tổng kết
Hãy thêm một nút bấm "Xuất Báo Cáo Excel" ở góc phải bảng xếp hạng. Khi người quản trị bấm vào, web sẽ tự động xuất ra file Excel hoặc CSV gồm các cột: Tên vận động viên, Đội, Tổng số km hợp lệ, Số buổi chạy, Số tiền thưởng, Số tiền phạt và Nợ km. Hãy chọn thư viện nhẹ và tối ưu nhất.
🎨 Tùy biến giao diện (Đổi màu, Banner, Hiệu ứng)
Tôi muốn giao diện có phong cách mùa Thu Đông rực rỡ hơn: hãy thêm hiệu ứng lá phong hoặc tuyết rơi nhẹ nhàng ở phần Countdown Banner, đổi tone màu nút bấm sang gradient ấm áp cam - đỏ thể thao, và làm cho thẻ thành tích khi chia sẻ lên mạng xã hội nhìn chuyên nghiệp và đẹp mắt hơn.
🛠️ Khi gặp bất kỳ lỗi gì lạ
Tôi vừa gặp lỗi sau khi chạy ứng dụng trên máy: [DÁN TOÀN BỘ ĐOẠN CHỮ ĐỎ BÁO LỖI HOẶC CHỤP ẢNH MÀN HÌNH VÀO ĐÂY]. Hãy phân tích nguyên nhân bằng tiếng Việt đơn giản dễ hiểu và tự động sửa dứt điểm lỗi này giúp tôi nhé!

Xử Lý Nhanh Các Tình Huống Thường Gặp

1. Cổng 3026 bị báo "Port already in use" (Trùng cổng) Xem cách sửa ▾

Nghĩa là có một cửa sổ lệnh trước đó đang chạy chưa tắt. Bạn chỉ cần mở Task Manager (nhấn Ctrl + Shift + Esc) ➔ Tìm mục Node.js: Server-side JavaScript ➔ Bấm End task rồi chạy lại npm run dev.

2. Bấm kết nối Strava bị báo lỗi "redirect_uri mismatch" Xem cách sửa ▾

Vào lại trang Strava API Settings ➔ Kiểm tra ô Authorization Callback Domain xem có bị thừa chữ http:// hoặc :3026 không. Chỉ để duy nhất một từ: localhost.

3. Quên cách tắt máy chủ web sau khi làm việc xong Xem cách sửa ▾

Tại cửa sổ Terminal đang chạy npm run dev, bạn chỉ cần nhấn tổ hợp phím Ctrl + C (rồi gõ y nếu được hỏi) là máy chủ sẽ dừng lại an toàn.
