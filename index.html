Bước 2: Gửi "Siêu Prompt" Để AI Tự Cài Git, Node.js & Kéo Code Về Máy

Tùng chỉ cần bấm "Copy Siêu Prompt Này" rồi dán vào khung chat Antigravity!

Tùng bấm nút này để copy:
Chào bạn, tôi là Tùng, tôi mới tiếp nhận dự án webapp CNHP Challenge 2026. Máy tính của tôi là máy mới và tôi không thạo kỹ thuật lập trình. Hãy làm trọn gói từ A đến Z giúp tôi: 1. Kiểm tra máy tính xem đã có Git và Node.js chưa. 2. Nếu máy CHƯA CÓ Git hoặc Node.js, bạn hãy tự động chạy lệnh cài đặt chúng giúp tôi qua công cụ winget của Windows (ví dụ: "winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements" và "winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements"). 3. Tiếp theo, hãy tự động tải (clone) toàn bộ mã nguồn dự án từ link GitHub sau về máy giúp tôi: https://github.com/nhhacic/cnhp-challenge-2026.git 4. Sau khi tải code về, hãy tự động chạy lệnh "npm install" để cài đặt toàn bộ thư viện cần thiết. 5. Sau khi cài xong, hãy tự động chạy lệnh "npm run test:rules" để kiểm tra 26 ca kiểm thử thể lệ chạy bộ xem đã PASS 100% chưa. 6. Báo cáo kết quả chi tiết bằng tiếng Việt thật dễ hiểu cho tôi nhé!

Khi Antigravity chuẩn bị chạy các lệnh cài đặt phần mềm trên Windows, trên màn hình chat sẽ xuất hiện một ô vuông xin phép kèm nút bấm màu xanh Proceed (hoặc Chấp nhận). Bước 3: Lấy Strava API & Bảo AI Tự Điền Vào Dự Án

Giúp mọi người đồng bộ tự động bài chạy từ Strava vào webapp

1. Mở trang tạo API của Strava (Miễn phí 100%):

Truy cập: https://www.strava.com/settings/api ➔ Đăng nhập Strava của Tùng.

Application Name: CNHP Challenge 2026
Website: http://localhost:3026
Authorization Callback Domain: localhost (chỉ gõ đúng chữ localhost)

Bấm Create ➔ Strava sẽ cấp cho Tùng: Client ID (dãy số) và Client Secret (bấm nút Show để xem).

2. Copy Prompt này, dán Client ID/Secret của bạn vào rồi gửi cho AI:
Tôi vừa đăng ký xong Strava API, đây là thông tin của tôi: - Client ID: [DÁN_DÃY_SỐ_CLIENT_ID_VÀO_ĐÂY] - Client Secret: [DÁN_DÃY_KÝ_TỰ_CLIENT_SECRET_VÀO_ĐÂY] Hãy giúp tôi tự động tạo file ".env.local" ở thư mục gốc của dự án và điền đúng các biến NEXT_PUBLIC_STRAVA_CLIENT_ID, STRAVA_CLIENT_ID và STRAVA_CLIENT_SECRET nhé!

Kho Prompt Mẫu Nâng Cấp Webapp Theo Yêu Cầu Của Tùng

Tùng muốn sửa tính năng gì, chỉ cần copy câu tương ứng rồi gửi cho Antigravity!

👥 1. Thêm thành viên mới hoặc đổi tên đội
Hãy mở file data/challenge_data.json và giúp tôi thêm 1 thành viên mới tên là "Trần Văn Bình" vào đội "Chiến Binh CNHP", mục tiêu cá nhân là 20km/tuần. Sau khi thêm, hãy cập nhật lại bảng xếp hạng giúp tôi nhé!
💰 2. Cập nhật mức tiền phạt hoặc tiền thưởng
Ban tổ chức vừa cập nhật thể lệ: mức phạt thiếu buổi chạy tăng lên 30.000đ/buổi, và thưởng Đội Nhất tuần tăng lên 200.000đ. Hãy tìm tất cả các chỗ tính toán trong src/lib/rules-engine.ts và giao diện để sửa lại đúng số tiền mới, rồi tự chạy lại lệnh "npm run test:rules" để kiểm tra tính chính xác giúp tôi.
📊 3. Thêm tính năng xuất file Excel báo cáo
Hãy thêm một nút bấm "Xuất Báo Cáo Excel" ở góc phải của Bảng xếp hạng. Khi người quản trị bấm vào, web sẽ tự động xuất ra file Excel/CSV gồm các cột: Tên VĐV, Đội, Tổng km hợp lệ, Số buổi chạy, Tiền thưởng, Tiền phạt và Số km nợ tuần này.
🎨 4. Tùy biến giao diện (Không khí Thu Đông, Màu sắc, Banner)
Tôi muốn giao diện có phong cách mùa Thu Đông rực rỡ và chuyên nghiệp hơn: hãy thêm hiệu ứng lá phong rơi nhẹ ở phần Countdown Banner, đổi màu sắc các nút bấm sang tông cam - đỏ thể thao năng động, và làm cho thẻ chia sẻ thành tích cá nhân nhìn thật đẹp mắt khi chia sẻ lên mạng xã hội nhé!
☁️ 5. Đẩy code mới lên GitHub để lưu trữ an toàn
Tôi vừa cùng bạn chỉnh sửa xong các tính năng mới cho web. Hãy giúp tôi tự động kiểm tra bằng "npm run build", nếu bản build tốt đẹp thì hãy tự động tạo git commit và đẩy (push) toàn bộ code mới này lên nhánh main trên GitHub giúp tôi nhé!
